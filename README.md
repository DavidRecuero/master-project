# Pipe Mess

A casual mobile puzzle game for Android, built in Unity 6000.3.22f1.

Colored items travel through pipes onto a tray with limited space. Tap the items at the pipe exits to send them to the tray, and group three of the same color to clear them. Fill the tray and the level is lost.

Pipe Mess is the final project for my Master's degree (Universitat Oberta de Catalunya).
